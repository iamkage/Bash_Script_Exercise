# Bash Scripting & Linux Administration Exercises

## 🎯 Purpose & Scope
This repository serves as a personal hands-on laboratory for Linux system administration, core utilities, and Bash automation scripting. It contains practical exercises and utility scripts designed to test and refine command-line proficiency, POSIX compliance, process management, and task automation techniques in Linux environments.

## 🛠️ Key Topics & Concepts Practiced
* **Shell Fundamentals:** Variables, conditional logic (`if`/`case`), loops (`for`/`while`), function modularity, and error handling (`set -e`, exit codes).
* **Text Processing & Utilities:** Standard I/O redirection, piping, `grep`, `sed`, `awk`, and regular expressions.
* **System Administration:** File permissions and ownership (`chmod`/`chown`), process management (`kill`, `ps`, `top`), and Cron task scheduling.
* **Script Robustness:** Input validation, parameter parsing (`getopts`), and defensive variable handling.

## ⚠️ Note for Reviewers
These scripts were created as iterative practice exercises and technical experiments rather than a monolithic production application. The primary focus of this repository is code readability, POSIX compatibility, and practical system maintenance patterns.
